### 01. train / val / test

**배우기 / 고르기 / 최종 성적**을 나눈다.

#### 직관

연습 문제 · 모의고사 · 본고사다.  
본고사(test)로 반복 튜닝하면 또한 외우게 된다.

#### 핵심 성질

| 집합 | 역할 |
| :--- | :--- |
| train | 파라미터 학습 |
| validation | 모델·하이퍼 선택 |
| test | 최종 보고용 (가능하면 한 번) |

```python
data = list(range(10))
train, val, test = data[:6], data[6:8], data[8:]
print(train, val, test)
```

---

### 02. 과적합 / 과소적합

**외움 vs 덜 배움.**

#### 직관

연습만 100점인데 실전 0점이면 과적합,  
연습도 실전도 못하면 과소적합에 가깝다.

#### 핵심 성질

| 상태 | 감각 |
| :--- | :--- |
| 과적합 | train ↑, val/test ↓ |
| 과소적합 | 둘 다 낮음 |
| 완화 | 더 데이터, 정규화, 단순한 모델, 조기 종료 |

---

### 03. 분류 지표

**맞춘 개수만으로 부족할 때가 많다.**

#### 직관

희귀 질병 검사다.  
항상 “정상”이라 해도 정확도는 높을 수 있다.

#### 핵심 성질

| 지표 | 감각 |
| :--- | :--- |
| Accuracy | 전체 중 맞춘 비율 |
| Precision | 양성이라고 한 것 중 진짜 |
| Recall | 진짜 양성 중 찾아낸 비율 |
| F1 | 정밀도·재현율 조화 |

```python
# TP/FP/FN으로 정밀도·재현율
tp, fp, fn = 8, 2, 3
precision = tp / (tp + fp)
recall = tp / (tp + fn)
print(round(precision, 2), round(recall, 2))
```

---

### 04. 회귀 지표

**숫자 예측의 틀린 크기.**

#### 직관

예상 도착 시간과 실제의 차이(분)다.

#### 핵심 성질

| 지표 | 감각 |
| :--- | :--- |
| MAE | 절대 오차 평균 |
| MSE / RMSE | 큰 오차에 더 민감 |

```python
y_true = [10, 20, 30]
y_pred = [12, 18, 33]
mae = sum(abs(a - b) for a, b in zip(y_true, y_pred)) / len(y_true)
print(mae)
```
