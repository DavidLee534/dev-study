# 깃허브에 공부 글을 남기는 이유

## 들어가며

짧게 메모만 남기기보다, 티스토리에 쓰던 것처럼 **하나의 주제 글**로 정리하면 나중에 다시 읽기 좋습니다.  
코드 공부라면 설명과 함께 **실제 언어 코드**도 같이 남기는 게 좋습니다.

## 글 + 코드로 남기는 방법

1. `posts/`에 글을 작성합니다.
2. 글 안에 코드 블록으로 언어를 명시합니다. (` ```java `, ` ```sql ` 등)
3. 파일이 길어지면 `code/java/`, `code/python/` 같은 폴더에 소스 파일을 두고 글에서 링크합니다.

### 예시 · Java

```java
String jpql = """
    select m
    from Menu m
    join fetch m.category
    where m.status = 'ACTIVE'
    """;
```

전체 예시 파일: [`code/java/n1-demo/MenuService.java`](../../code/java/n1-demo/MenuService.java)

## 정리

- 공부 글은 **설명 + 코드**가 한 세트입니다.
- 언어는 Java뿐 아니라 JS/TS/Python/SQL/Bash 모두 `code/` 아래에 두면 됩니다.
