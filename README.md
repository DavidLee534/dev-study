# Dev Study

백엔드 개발 공부 내용을 정리해 두는 저장소입니다.

Java, Spring Boot, JPA, PostgreSQL, Docker를 중심으로  
학습한 개념, 문제 해결 과정, 코드 예시를 남깁니다.

## 공부 범위

- **Java** — 언어 문법, 컬렉션, 동시성
- **Spring** — Spring Boot, Spring Data JPA, Security
- **Database** — PostgreSQL, 쿼리, 트랜잭션
- **Infra** — Docker, 서버 구성, 배포 기초
- **CS** — HTTP, 운영체제, 네트워크 기초

## 이 저장소를 쓰는 방식

1. 주제를 하나 정합니다. (예: JPA N+1, JWT 인증 흐름)
2. 이해한 내용과 코드를 문서로 정리합니다.
3. 커밋해서 기록으로 남깁니다.

```bash
git add .
git commit -m "study: JPA N+1 정리"
git push
```

## 기록 원칙

- 완벽하지 않아도 됩니다. **오늘 이해한 것**을 남깁니다.
- 가능하면 **문제 → 원인 → 해결 → 코드** 순서로 적습니다.
- 짧은 메모보다, 나중에 다시 읽을 수 있는 설명을 남깁니다.
