> 클래스 이름은 숫자로 시작할 수 없어서 `L01_` 접두사를 붙였다. (Lesson)

기초(`L01` ~ `L24`) 다음에 이어서 공부한다.  
번호는 `L01_`부터 다시 시작한다.

```bash
cd language/java/심화/code
javac L01_Class.java
java L01_Class
```
