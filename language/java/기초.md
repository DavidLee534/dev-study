한 코드 파일 = 한 문법. 자세한 설명은 각 `.java` 주석에 있다.

> 클래스 이름은 숫자로 시작할 수 없어서 `L01_` 접두사를 붙였다. (Lesson)

파일명 `L01_` … `L24_` 순서로 공부하면 된다.

```bash
cd language/java/기초/code
javac L01_MainMethod.java
java L01_MainMethod
```
